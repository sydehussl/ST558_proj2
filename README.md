# ST 558 Project 2

My planning document is found at **[hyperlink to site](https://docs.google.com/document/d/1kiX-CtG-5Y56IHK-flUB6jmYweiX84sbeAxlZh63VDg/edit?usp=sharing)**.

The goal of this app is to allow users to browse the mobile phone usage dataset. This is a synthetic data set created for machine learning practice, it can be found at **[this link](https://www.kaggle.com/datasets/valakhorasani/mobile-device-usage-and-user-behavior-dataset/data)**.

Users can filter and subset the data. They can download the resulting data or view numerical summaries and graphs.
